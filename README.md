# 4S

Sam's Sequencer and Synthesizer Set -- a modular electronic music suite with a
Rust audio daemon, a CLI, and a thin Electron UI.

First milestone: a TR-808-style drum sequencer played from a Livid Block.

Status: early design. See [AGENTS.md](AGENTS.md) for principles and
[docs/](docs/) for design notes.

## Prerequisites (planned)

- Rust toolchain (via rustup)
- Node.js 22+
